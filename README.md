## 🚀 What I do

I connect systems, data and AI so they work together in production:

- 🔄 **Data integration**: connectors, ETL/feed pipelines and format transformation (CSV ⇄ XML, marketplaces, catalogues, APIs)
- 🤖 **AI agent integration**: giving agents safe, well-defined access to real systems through protocols, tool interfaces and authorization controls
- 🧠 **Applied ML**: turning models (e.g. transformers) into practical solutions such as classification and categorization on real business data
