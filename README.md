## What I do

Six years in ecommerce and marketplace data. At **Tradebyte (Zalando Group)** I lead enterprise channel integrations end to end: discovery, solution design, API and data-exchange implementation, testing and go-live, across product data, stock, prices, orders and cancellations.

Results from that work: full price-feed processing **6x faster**, stock-feed import cut from **5 minutes to under 1 minute**.

I also build what I design. Here on GitHub that means n8n nodes, marketplace connectors and AI agent tooling.

- 🔄 **Commerce data integration**: APIs, feeds, JSON/XML/CSV mapping, marketplaces (Mirakl, Tradebyte, OTTO), Boomi
- ⚙️ **Workflow automation**: custom n8n nodes in TypeScript, webhooks, trigger-based flows
- 🤖 **AI and agents**: RAG knowledge bases, Gemini API automation, agent access to real systems (UCP / ACP)
